# misc.h - small miscellaneous C library
This is a small C library containing some small features for
future usage simplicity. It is intendedd for personal use.

## Implemented content
- [ ] Slice            (pointer to a fat pointer masked by a double pointer to datatype)
- [x] Vector           (pointer to a length & capacity prefixed array masked by a single pointer)
- [ ] Hashmap          (simple hashmap masked by pointer to a special key / value struct)
- [ ] System           (general system manipulations like creating & reading files)
- [ ] Build system     (replacement to a regular shell script purely in C)
