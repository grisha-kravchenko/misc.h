# misc.h - small miscelaneous C library
This is a small C library containing some small features for
future usage simplicity. It is intendedd for personal use.

## Implemented content
[X] Slice            (pointer to a fat pointer masked by a double pointer to datatype)
[+/-] Vector           (pointer to a length & capacity prefixed array masked by a single pointer)
[X] System           (general system manipulations like creating & reading files)
[X] Build system     (replacement to a regular shell script purely in C)
